## 归档与版本

每场保存本人训练日志（无损 `.jsonl.gz`）、公开事件、结果PNG、说明及校验清单。训练日志解压后的SHA-256与原文件一致，决策区校验也与export_complete相符。截图保存时间不替代实际开赛日期。

公开事件和回放只辅助离线分析，实时策略只使用当时合法观察。比赛提交包不要包含本目录。

现有策略开发版本为V1。用户下一轮计划提交V1，在取得实际新对局后，应新建后续对局文件夹，记录平台版本ID和实际使用策略；不可把这里的V0成绩计为V1成绩。

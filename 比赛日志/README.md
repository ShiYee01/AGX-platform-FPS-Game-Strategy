## 归档与版本

每场保存本人训练日志（无损 `.jsonl.gz`）、公开事件、结果PNG、说明及校验清单。训练日志解压后的SHA-256与原文件一致，决策区校验也与export_complete相符。截图保存时间不替代实际开赛日期。

公开事件和回放只辅助离线分析，实时策略只使用当时合法观察。比赛提交包不要包含本目录。

现有开发策略为V2，入口 `agent/agent.py`。第12～18局的真实成绩属于V1；固定观察上的V2验证不产生新比赛成绩。参见[V2修改说明](../策略更新/V2-稳定目标与分级脱困/修改说明.md)。

[基线指标](基线指标/对局02-18-统一指标.json)由 `tools/analyze_matches.py --no-replay` 生成，第2～18局按平台 version_id 分组，口径与后续新对局一致（停滞：指令移动3秒走不到0.3米；冻结：存活时整个 `me` 连续5秒以上不变）。第19局起的新对局由本地会话按 [交接/2026-11-24-本地日志分析任务.md](../交接/2026-11-24-本地日志分析任务.md) 归档，实际版本以 `reproduced_by` 逐条复现结果为准。

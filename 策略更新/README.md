# FPS 策略更新

当前开发版本为 **V4-全速移动与危险点预瞄**，入口 `agent/agent.py`。平台网站的版本号按上传次数计，网站“v4”是本仓库V2。GitHub推送不替代AGX上传和参赛版本选择。

| 版本 | 内容 | 实际比赛状态 |
| --- | --- | --- |
| V0 | 工具包原版 | 对局01为赛前测试；正式对局02～11为5胜5负 |
| V1 | 保留合法获知的已安放炸弹坐标，新目标覆盖旧脱困 | 实际对局12～18为4胜3负；第18局验证了坐标消失后保持目标 |
| V2 | 到点观察后换点；按路径进度判断受阻；分级脱困及暂避失败连接 | 平台显示v4；对局19～28逐条复现为V2，4胜5负1平（日志仅在本机），约85～90局未下载 |
| V3 | A*按米选路并删除>1.4 m陡升；包位置未知时按提示音距离回防、空包点0.5秒后换点；开火门限随距离收紧并要求扩散回落和蹲下完成；错峰减半 | 35项行为测试及对局01～18固定观察检查；第二轮本地核查在对局19～28确认其三条依据；2026-11-24 已上传AGX，准入与对局未确认，无实战日志 |
| V4 | 寻路全速（0.75→1.0）；进攻时视线对准已知防守枪位；受击0.5秒内退回V2开火门限 | 41项行为测试及对局01～18固定观察检查；尚无实战 |
